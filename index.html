01 / PROFIL

Tentang Saya

Ketertarikan pada teknologi diwujudkan melalui eksplorasi, perancangan, dan pengerjaan proyek.

Saya adalah mahasiswa D4 Teknik Mekatronika di Politeknik Elektronika Negeri Surabaya (PENS) dengan minat pada robotika, otomasi industri, embedded systems, dan desain mekanik.

Saya senang mengembangkan proyek yang mengintegrasikan aspek mekanik, elektronika, dan pemrograman, mulai dari pemodelan 3D dan perakitan hingga pengembangan sistem kendali serta troubleshooting.

Melalui proyek akademik, kompetisi, dan pelatihan teknis, saya terus mengembangkan pengetahuan serta keterampilan praktik. Saya terbuka untuk kesempatan magang, kolaborasi, dan pengalaman profesional.

02 / PROYEK

Kumpulan Karya dan Implementasi

Berbagai proyek yang telah saya kerjakan selama perkuliahan maupun secara mandiri, meliputi bidang robotika, otomasi, elektronika, dan mekanik & fabrikasi.

“

Setiap proyek adalah langkah kecil menuju versi terbaik dari diri sendiri.

01
Robotika

Self-Balancing Robot

Robot beroda dua dengan prinsip inverted pendulum menggunakan sensor IMU MPU6050 dan algoritma PID pada ESP32 untuk menjaga keseimbangan otomatis.

ESP32 PID Control MPU6050
02
Robotika

2-DOF Planar Robot Arm

Program C++ pada board OpenCM9.04 dan servo Dynamixel untuk menerapkan Forward & Inverse Kinematics dalam menggerakkan lengan robot mengikuti lintasan.

C++ OpenCM9.04 Dynamixel
03
Otomasi

HMI Coffee Vending Machine

Merancang antarmuka Human Machine Interface (HMI) menggunakan EasyBuilder Pro untuk simulasi pengoperasian mesin kopi otomatis berbasis koin.

EasyBuilder Pro HMI Automation
04
Elektronika

Sistem Alarm Suhu LM35

Rangkaian kontrol analog peringatan suhu berlebih menggunakan sensor LM35 dan komparator op-amp LM741 lengkap dengan perancangan jalur PCB.

LM35 LM741 PCB Layout
05
Mekanik & Fabrikasi

CNC Pen Plotter

Realisasi desain konseptual 3D ke pembuatan perangkat keras mencakup fabrikasi struktur mekanik, penyelarasan rangka, dan perakitan motor stepper.

3D CAD Stepper Fabrication
06
Otomasi

Modbus RTU PLC FX3U

Implementasi komunikasi serial Modbus RTU dengan PLC FX3U sebagai Master untuk membaca data sensor suhu & kelembaban dan menampilkannya ke Seven Segment.

PLC FX3U Modbus RTU RS485
07
Otomasi

Kontrol Display Modbus RTU

Implementasi protokol Modbus RTU dengan PLC FX3U sebagai Master untuk menulis nilai register data secara langsung menuju modul penampil Seven Segment (Slave).

PLC FX3U Modbus Slave Seven Segment

Kategori Proyek

Teknologi yang Digunakan

C++ ESP32 PID Control PLC FX3U Modbus RTU EasyBuilder Pro OpenCM9.04 Dynamixel Inventor Fusion 360 Proteus
